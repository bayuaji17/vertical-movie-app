# Elysia with Bun runtime

## Getting Started
To get started with this template, simply paste this command into your terminal:
```bash
bun create elysia ./elysia-example
```

## Development
To start the development server run:
```bash
bun run dev
```

Open http://localhost:3001/ with your browser to see the result. Set `PORT` to use another port.

## Production

Build and start the API with Bun:

```bash
bun run build
bun run start
```
